# Network reduction

Network reduction is a technique used in power system analysis to simplify large-scale electrical networks 
while preserving their electrical characteristics on a specific area of interest (the internal zone). 
PowSyBl Open Load Flow provides an implementation of network reduction based on the Ward equivalent method.
